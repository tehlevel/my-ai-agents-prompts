# 📝 Content
Работа с текстом и медиа: транскрибация, саммари, перевод, копирайтинг, конвертация файлов.

## 🤖 Состав категории

- *../adaptive-explainer* **Адаптивный консультант**, который динамически меняет свою экспертную роль в зависимости от тематики запроса.
- *../clean-verbatim-transcriber* **Транскрибатор** - превращает устную речь в читаемый литературный текст, убирая мусор.
- *../cognitive-synthesizer* **Синтезатор смыслов** - глубокая переработка информации, объединение разных источников в один смысл.
- *../universal-pdf-to-md* **Конвертер PDF** документов в чистый Markdown для дальнейшей работы в Obsidian/LLM.
- *../freelance-bid-sniper* Специализированный **Агент-копирайтер** для генерации высококонверсионных сопроводительных писем (Cover Letters).
