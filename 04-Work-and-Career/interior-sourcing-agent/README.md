# Interior Sourcing Agent (v2.0)

## Описание
Профессиональный агент-комплектатор для дизайнеров интерьеров. Специализируется на поиске мебели, отделочных материалов и декора в регионах РБ, РФ, Польши и Китая. 

## Ключевые особенности
- **Smart Search Links:** Вместо битых прямых ссылок генерирует готовые поисковые запросы в Google, гарантируя актуальность выдачи.
- **Анализ качества:** Приоритет отдается реальным отзывам и техническим характеристикам, а не маркетинговым описаниям.
- **Региональная адаптация:** Умеет искать на локальных языках и маркетплейсах (Allegro, Avito, Alibaba и др.).
- **Защита от галлюцинаций:** Строгий запрет на выдумывание URL-адресов.

## Рекомендуемые параметры (Configuration)
*Основано на архетипе: Type 4 (Verified Research)*

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Temperature** | 1.0 | Необходима для вариативности поисковых запросов и гипотез. |
| **Thinking Level**| High | Критически важно для анализа отзывов и синтеза обоснования выбора. |
| **Google Search** | ON | Основной инструмент для получения актуальных данных. |
| **URL Context** | ON | Позволяет анализировать содержимое найденных страниц. |
