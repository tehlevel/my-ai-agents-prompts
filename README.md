# 🧠 AI Agents Vault

Централизованное хранилище системных инструкций (промптов) для ИИ-агентов.
**Цель:** Версионирование, структурирование и быстрое развертывание персональных ассистентов.

## 🗺️ Навигация

### [🏗️ 01-AI-Builders](./01-AI-Builders)
**Meta-уровень.** Инструменты для создания, аудита и улучшения самих промптов.
#### 🤖 Состав категории

- [**Аудитор промптов**](./01-AI-Builders/Prompt-Auditor) - специализированный агент-эксперт, выполняющий роль Senior Prompt Engineer при проведении Code Review.
- [**Архитектор промптов**](./01-AI-Builders/ai-architect-v6) - агент для проектирования, аудита и создания профессиональных системных инструкций.

### [📝 Content](./02-content)
**Текст и Медиа.** Самая насыщенная категория. Транскрибация, синтез смыслов, генерация заявок (Bid Sniper) и конвертация форматов.
#### 🤖 Состав категории

- [**Адаптивный консультант**](./02-content/adaptive-explainer), который динамически меняет свою экспертную роль в зависимости от тематики запроса.
- [**Транскрибатор**](./02-content/clean-verbatim-transcriber) - превращает устную речь в читаемый литературный текст, убирая мусор.
- [**Синтезатор смыслов**](./02-content/cognitive-synthesizer) - глубокая переработка информации, объединение разных источников в один смысл.
- [**Конвертер PDF**](./02-content/universal-pdf-to-md) документов в чистый Markdown для дальнейшей работы в Obsidian/LLM.
- [**Специализированный Агент-копирайтер**](./02-content/freelance-bid-sniper) для генерации высококонверсионных сопроводительных писем (Cover Letters).

### [📊 Data and Code](./03-Data-and-Code)
**Данные и Код.** Работа с таблицами, финансовой информацией и помощь в разработке (Junior Dev).
#### 🤖 Состав категории

- [**Финансовый скаут (BY)**](./03-Data-and-Code/belarus-finance-scout) - поиск и анализ финансовой информации, курсов, налогов (специфика Беларуси).
- [**Архитектор Google Sheets**](./03-Data-and-Code/google-sheets-architect) - проектирование сложных таблиц, скриптов Apps Script и формул.
- [**Junior Dev помощник**](./03-Data-and-Code/junior-dev-data-buddy) - ассистент по базовым задачам с данными и кодом (Python/SQL/Pandas).

### [🚀 Work and Career](./04-Work-and-Career)
**Карьера и Фриланс.** Стратегическое планирование карьеры и менторство (с фокусом на рынок РБ).
#### 🤖 Состав категории
- [**Ментор для 3D-дизайнеров**](./04-Work-and-Career/3d-design-mentor) и визуализаторов. Действует как опытный коллега, помогая оптимизировать пайплайн работы.
- [**Карьерный Стратег**](./04-Work-and-Career/career-strategy-architect) - помогает построить стратегию развития и позиционирования карьеры.
- [**Наставник для операторов молочного производства**](./04-Work-and-Career/dairy_mentor_pro), цель которых — карьерный рост до Инженера-Технолога.
- [**Виртуальный управляющий партнер**](./04-Work-and-Career/design-studio-mentor) для запуска и масштабирования гибридной дизайн-студии (Рендер + Фото/Видео + Чертежи + AI) в Беларуси.
- [**Управляющий проектами агент**](./04-Work-and-Career/freelance-ops-manager) - высокоуровневый агент, который управляет фриланс-процессами.
- [**Профессиональный агент-комплектатор**](./04-Work-and-Career/interior-sourcing-agent) для дизайнеров интерьеров. Специализируется на поиске мебели, отделочных материалов и декора в регионах РБ, РФ, Польши и Китая.
- [**Ментор для производственной среды**](./04-Work-and-Career/social-dynamics-navigator) ("синие воротнички"). Помогает сотрудникам выстраивать карьеру в условиях жесткой иерархии, анализировать расстановку сил в коллективе и наращивать влияние через профессионализм.
