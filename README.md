# 🧠 AI Agents Vault

Централизованное хранилище системных инструкций (промптов) для ИИ-агентов.
**Цель:** Версионирование, структурирование и быстрое развертывание персональных ассистентов.

## 🗺️ Навигация

### [🏗️ 01-AI-Builders](./01-AI-Builders)
**Meta-уровень.** Инструменты для создания, аудита и улучшения самих промптов.
#### 🤖 Состав категории

- *../Prompt-Auditor* [**Аудитор промптов**](./Prompt-Auditor) - специализированный агент-эксперт, выполняющий роль Senior Prompt Engineer при проведении Code Review.
- *../ai-architect-v6* **Архитектор промптов** - агент для проектирования, аудита и создания профессиональных системных инструкций.

### [📝 Content](./02-content)
**Текст и Медиа.** Самая насыщенная категория. Транскрибация, синтез смыслов, генерация заявок (Bid Sniper) и конвертация форматов.
#### 🤖 Состав категории

- *../adaptive-explainer* **Адаптивный консультант**, который динамически меняет свою экспертную роль в зависимости от тематики запроса.
- *../clean-verbatim-transcriber* **Транскрибатор** - превращает устную речь в читаемый литературный текст, убирая мусор.
- *../cognitive-synthesizer* **Синтезатор смыслов** - глубокая переработка информации, объединение разных источников в один смысл.
- *../universal-pdf-to-md* **Конвертер PDF** документов в чистый Markdown для дальнейшей работы в Obsidian/LLM.
- *../freelance-bid-sniper* Специализированный **Агент-копирайтер** для генерации высококонверсионных сопроводительных писем (Cover Letters).

### [📊 Data and Code](./03-Data-and-Code)
**Данные и Код.** Работа с таблицами, финансовой информацией и помощь в разработке (Junior Dev).
#### 🤖 Состав категории

- *../belarus-finance-scout* **Финансовый скаут (BY)** - поиск и анализ финансовой информации, курсов, налогов (специфика Беларуси).
- *../google-sheets-architect* **Архитектор Google Sheets** - проектирование сложных таблиц, скриптов Apps Script и формул.
- *../junior-dev-data-buddy* **Junior Dev помощник** - ассистент по базовым задачам с данными и кодом (Python/SQL/Pandas).

### [🚀 Work and Career](./04-Work-and-Career)
**Карьера и Фриланс.** Стратегическое планирование карьеры и менторство (с фокусом на рынок РБ).
#### 🤖 Состав категории
- *../3d-design-mentor* **Ментор для 3D-дизайнеров** и визуализаторов. Действует как опытный коллега, помогая оптимизировать пайплайн работы.
- *../career-strategy-architect* **Карьерный Стратег** - помогает построить стратегию развития и позиционирования карьеры.
- *../dairy_mentor_pro* **Наставник для операторов молочного производства**, цель которых — карьерный рост до Инженера-Технолога.
- *../design-studio-mentor* **Виртуальный управляющий партнер** для запуска и масштабирования гибридной дизайн-студии (Рендер + Фото/Видео + Чертежи + AI) в Беларуси.
- *../freelance-ops-manager* **Управляющий проектами агент** - высокоуровневый агент, который управляет фриланс-процессами.
- *../interior-sourcing-agent* **Профессиональный агент-комплектатор** для дизайнеров интерьеров. Специализируется на поиске мебели, отделочных материалов и декора в регионах РБ, РФ, Польши и Китая.
- *../social-dynamics-navigator* **Ментор для производственной среды** ("синие воротнички"). Помогает сотрудникам выстраивать карьеру в условиях жесткой иерархии, анализировать расстановку сил в коллективе и наращивать влияние через профессионализм.
