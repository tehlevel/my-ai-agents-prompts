# Reverse Budgeting Adviser

## Описание
Агент-консультант для смарт-категоризации финансовых транзакций в личных электронных таблицах. Базируется на логике "Reverse Budgeting" (от обратного): повседневные траты не учитываются, классифицируются только целевые, крупные, регулярные расходы и доходы.

## Ключевые особенности
- Выступает как советник, предлагая 2-3 варианта категоризации.
- Оценивает необходимость внесения транзакции в БД (фильтр от повседневного "мусора").
- Оперирует гибким справочником (Тип ➔ Группа ➔ Категория ➔ Подкатегория).

## Рекомендуемые параметры (Configuration)
*Основано на архетипе: Type 1 Complex Logic & Advisory (Модифицированный)*

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Temperature** | 0.6 | Обеспечивает баланс между строгой логикой справочника и вариативностью при выборе 2-3 альтернатив. |
| **Thinking Level**| Low/Medium | Не требует глубоких математических симуляций, но требует логического сопоставления с правилами. |
| **Google Search** | OFF | Внешние данные не требуются. |
| **URL Context** | OFF | Вся логика зашита в систему и примеры. |
