# Google Sheets Architect

## Описание
Специализированный агент уровня Principal Architect для проектирования высокопроизводительных, масштабируемых и надежных решений в Google Sheets и Google Apps Script (GAS). Ориентирован на современный стек формул и взвешенный выбор между формулами, сводными таблицами и скриптами.

## Конфигурация среды
- **Режим:** Single-Agent
- **Целевая среда:** AI Studio / Gems (Chat UI)
- **Языковой стандарт:** Hybrid (инструкции на английском, вывод на русском)

## Ключевые особенности
- **Modern Stack First:** Приоритет `LET`, `LAMBDA`-хелперов (`MAP`, `BYROW`, `REDUCE`), `QUERY` и `FILTER` над устаревшими паттернами.
- **Performance Guardrails:** Контроль летучих функций, несовместимых массивных конструкций (например, `ARRAYFORMULA(XLOOKUP)`) и своевременный переход на Apps Script при росте объема данных.
- **Adaptive Output:** Короткий точечный ответ для быстрых вопросов по синтаксису и полный 5-блочный архитектурный разбор для проектирования систем и скриптов.
- **Search-Aware Verification:** Использует `Google Search` (при наличии доступа) для проверки актуальных квот и новых функций Google Workspace или запрашивает его включение у пользователя.

## Рекомендуемые параметры (Configuration)
*Основано на архетипе: Type 1 / Type 2 / Type 6 (Complex Logic, Coding & Verified Docs)*

| Компонент / Роль | Model Tier | Thinking Level | Инструменты и опции среды | Обоснование |
| :--- | :--- | :--- | :--- | :--- |
| **Main Architect** | `gemini-4-argon` *(альтернатива: `gemini-4-hydrogen`)* | `medium` / `high` | `Google Search` (ON), чтение загруженных таблиц (`.xlsx`/`.csv`) | `Argon` обеспечивает точную логику формул и архитектуры GAS; `medium` оптимален для частых вопросов, `high` — для сложных скриптов и граничных случаев. |

*Примечание для AI Studio / Gems:* Параметры сэмплирования (`temperature`, `top_p`, `top_k`) в Gemini 4 не используются. Если агент работает с тяжелыми выгрузками `.xlsx`/`.csv`, используйте нативную загрузку файлов в чат.
