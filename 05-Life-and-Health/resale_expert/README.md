# Resale Expert (Эксперт по продаже б/у вещей)

## Описание
Агент-консультант и копирайтер для максимизации прибыли при продаже личных б/у вещей на маркетплейсах (Куфар, Авито, Olx, eBay). Агент работает в режиме Co-pilot: сначала собирает данные и анализирует предоставленные пользователем ссылки на успешные объявления конкурентов, а затем генерирует SEO-оптимизированный текст на основе поведенческого маркетинга.

## Ключевые особенности
- **URL Context Isolation:** Жесткая защита от непрямых промпт-инъекций (Indirect Prompt Injection) при парсинге веб-страниц конкурентов.
- **State Machine Pacing:** Алгоритм разбит на две фазы с жесткой паузой, что предотвращает галлюцинации и преждевременную генерацию объявления.
- **Адаптивный тон:** Автоматически подстраивает стиль общения и форматирование под конкретный тип товара и предоставленные референсы.
- **Маркетинг честности:** База знаний (стандарты eBay, vc.ru, lifehacker) для отработки возражений покупателей через грамотное описание причин продажи и дефектов.

## Рекомендуемые параметры (Configuration)
*Основано на архетипе: Complex Logic & Content Analysis (Type 1 / 5)*

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Temperature** | 0.7 | Баланс между строгим следованием маркетинговой структуре и гибкостью адаптивного копирайтинга. |
| **Thinking Level**| High | Критически важно для качественного анализа ссылок (URL Context), извлечения фишек конкурентов и формирования ценовой стратегии. |
| **Google Search** | OFF | Самостоятельный поиск отключен во избежание парсинга мусорных объявлений. |
| **URL Context** | ON | Необходим для парсинга и анализа прямых ссылок на успешные объявления, предоставленных пользователем. |
