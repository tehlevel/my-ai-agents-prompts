# Childhood Mentor Strategist

## Описание
Персональный агент-консультант («Hub») по вопросам воспитания, возрастной психологии и развития ребенка. Спроектирован как долгосрочный партнер семьи, удерживающий гуманистические ценности (Зицер, Петрановская) и научно обоснованные стандарты безопасности (ВОЗ, AAP, ЮНЕСКО).

## Конфигурация среды
- **Режим:** Single-Agent (Повседневный Hub + ветвление через `/branch`)
- **Целевая среда:** Chat UI (Google AI Studio / Gemini Gems / ChatGPT)
- **Языковой стандарт:** Hybrid (английские структурные заголовки + русскоязычные правила, примеры и ответы; мультиязычный поиск)

## Ключевые особенности
- **Ценностный фильтр:** Отсекает карательные и вредные практики (физические наказания, стыд, «дать сдачи»), заменяя их доказательными и гуманистическими стратегиями.
- **Адаптивный формат:** Использует четкую структуру «Тезис → Анализ → План действий» для сложных ситуаций и переходит на теплый свободный диалог для эмоциональной поддержки.
- **Context Branching (`/branch`):** Сжимает релевантный контекст в блок кода для переноса сложных тем в новый чистый чат без шума старой переписки.
- **Редактируемый профиль:** Поля даты рождения, пола и среды оставлены пустыми с инструкцией по заполнению при настройке чата.

## Инструкция по использованию

### 1. Подготовка перед запуском
1. Скопируйте содержимое `SYSTEM_PROMPT.md` в системные инструкции (AI Studio, Gemini Gem или Custom GPT).
2. Заполните блок `## Профиль ребенка` актуальной датой рождения, полом и средой (язык, садик/школа, особенности). Периодически обновляйте раздел «Среда и контекст» при изменениях в жизни семьи.

### 2. Повседневный режим (Hub)
Используйте основной чат для регулярных вопросов и разбора ситуаций:
> *«Сегодня отказался есть суп и бросил ложку, я еле сдержался. Что делать?»*
> *«Я сорвался и накричал из-за мультиков, чувствую вину. Как помириться?»*

### 3. Режим глубокой проработки (Branching)
Для затяжных проблем (страхи, адаптация к саду, кризис границ) выносите тему в свежий чат:
1. Напишите `/branch` или *«Сделай бриф для новой сессии по этой теме»*.
2. Скопируйте сгенерированный блок кода.
3. Откройте новый чат с тем же агентом и вставьте текст.
