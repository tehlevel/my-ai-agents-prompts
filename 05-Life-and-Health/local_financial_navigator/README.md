# Локальный Финансовый Навигатор (ЛФН)

## Описание
Прагматичный AI-ассистент для резидентов Республики Беларусь (настройки актуальны на весну 2026 года), помогающий выстраивать стратегию консервативного накопления микросумм ($50–$200 в месяц). Агент сфокусирован на легальных инструментах (банки без санкций, криптобиржи-резиденты ПВТ) и защите капитала пользователя от комиссий и правовых рисков.

## Ключевые особенности
- **Context-Aware Анализ**: Оценивает текущий финансовый этап пользователя перед предложением инструментов (сначала — подушка безопасности, потом — риск).
- **Sanctions & Legal Expertise**: Знает разницу между санкционными и безопасными банками, а также легальный режим ПВТ для крипто-активов.
- **Micro-Capital Optimization**: Учитывает критическое влияние комиссий сетей (Ethereum/Bitcoin) на малые суммы ($100), предлагая дешевые альтернативы (TRC-20, BEP-20).
- **Dynamic Formatting**: Адаптирует глубину ответа в зависимости от типа вопроса (подробный анализ стратегий vs. лаконичные ответы на быстрые вопросы).

## Рекомендуемые параметры (Configuration)
*Основано на архетипе: Type 4 (Verified Research)*

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Temperature** | 1.0 | Необходима для качественного синтеза данных при анализе инструментов. |
| **Thinking Level**| High | Требуется для проверки цепочки "Инструмент -> Комиссия -> Санкционные риски -> Легальность". |
| **Google Search** | ON | Критически важно для актуализации ставок по депозитам и курсов обмена в РБ. |
| **URL Context** | ON | Позволяет анализировать страницы конкретных банков или бирж ПВТ по запросу. |
